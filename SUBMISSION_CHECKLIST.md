# Submission Checklist

1. Open a terminal in this project folder.
2. Create and activate a Python virtual environment.
3. Run:
   pip install -r requirements.txt
4. Run:
   python train.py
5. Wait for training to finish.
6. Confirm that `generated_text.txt` and `lstm_text_generator.keras` are created.
7. Review the generated text in `generated_text.txt`.
8. Create a GitHub repository named, for example:
   `lstm-text-generator`
9. Upload:
   - train.py
   - requirements.txt
   - README.md
   - generated_text.txt
   - .gitignore
10. Do NOT upload the `venv/` folder.
11. If the model file is too large for the submission, it can be omitted from
    GitHub; the README explains that it is created after training.
12. Copy the GitHub repository link into the test before finishing, or email
    the repository link to HR as instructed.

The practical PDF asks for code, generated text samples, and a dataset link
or download instructions.
